# Spatiotemporal Environmental Zoning Using GIS and Unsupervised Machine Learning

An exploratory GIS and machine-learning project that identifies Environmental patterns using spatial, environmental and seasonal variables.

## Project Overview

This project uses unsupervised machine learning to group environmental observations into zones based on similarities in:

- Soil moisture
- Land surface temperature
- NDVI
- LST
- Seasonal characteristics
- Geographic location

Instead of predicting predefined land-cover classes, the project uses K-Means clustering to discover exploratory environmental patterns within the dataset.
